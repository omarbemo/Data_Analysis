# Customer Personality Analysis 🚀

## 📌 Project Overview
This project performs an **Exploratory Data Analysis (EDA)** on customer marketing data to help a business understand its customers' profiles. By analyzing demographics, household structures, and spending habits, we identify the most profitable customer segments.

## 🛠 Skills & Tools
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Techniques:** Data Cleaning, Feature Engineering, Outlier Detection (IQR), Segment Analysis

## 📊 Key Insights
* **Income vs. Spending:** Strong positive correlation; high-income earners are the primary drivers of revenue.
* **Family Size:** Households with children show lower spending, suggesting a need for family-oriented promotions.
* **Campaign Impact:** Customers who accepted previous offers spend significantly more, proving the ROI of marketing efforts.
